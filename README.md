## 2. 目的・背景

教育現場での時間割作成作業は主に表計算ツールを使用して手作業でおこなわれる。手作業で教員と科目の重複を避けつつ最適な時間割を作成することは非常に難しく膨大な作業時間がかかる。そこで、テンプレートをインポートしてGUI上で操作するだけで手軽に作成できる時間割作成アプリを開発する。

## 3. 機能・特徴

- 作成した時間割をxlsx形式でエクスポート
- テンプレート（.xlsx）をインポート・エクスポート可能
- 科目が規定の時間数存在するかのステータス確認が可能
- ドラッグ＆ドロップで簡単編集
- ローカルファイルに自動保存（クラウド・DB不要）
- 軽量なTauriランタイムで動作
